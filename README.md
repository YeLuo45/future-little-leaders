- **GitHub 仓库**: https://github.com/YeLuo45/future-little-leaders

## 项目说明

## 技术栈

- uni-app（多平台框架）
- Vue 3

## 本地运行

```bash
npm install
npm run dev:h5
```

## 构建 H5

```bash
npm run build:h5
```

构建产物位于 `dist/build/h5/`。

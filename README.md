# 未来小领袖 - 亲子习惯养成平台

儿童教育与成长平台，帮助家长培养孩子良好习惯的互动学习工具。

## 访问地址

- **GitHub Pages**: https://yeluo45.github.io/future-little-leaders/
- **GitHub 仓库**: https://github.com/YeLuo45/future-little-leaders

## 功能特性

### 核心功能

| 功能 | 说明 |
|------|------|
| 宝宝管理 | 添加多个孩子，记录基本信息（姓名、生日、头像） |
| 每日任务 | 创建亲子成长任务，完成后获得积分奖励 |
| 周期性任务 | 习惯打卡功能（如每天阅读30分钟、按时睡觉） |
| 积分系统 | 完成任务获得积分，可用于商城兑换 |
| 积分商城 | 用积分兑换实物/虚拟奖励 |
| 任务统计 | 查看任务完成趋势，追踪成长进度 |
| 社区分享 | 发布孩子的成长点滴，与其他家庭分享 |
| 收藏功能 | 收藏喜欢的任务模板或商品 |

### 用户模块

| 模块 | 说明 |
|------|------|
| 登录/注册 | 用户账号系统 |
| 个人中心 | 个人信息管理 |
| 宝宝管理 | 孩子的信息维护 |
| 积分记录 | 积分收支明细 |
| 商品管理 | 积分商城商品浏览与兑换 |
| 帮助中心 | 使用指南与常见问题 |
| 设置 | 主题、隐私、协议等 |

## 技术栈

- **框架**: uni-app（多平台）
- **前端**: Vue 3 + Vite
- **状态管理**: Pinia 2.1.7
- **部署**: GitHub Pages (gh-pages)

## 本地开发

```bash
# 安装依赖
npm install

# H5 开发模式
npm run dev:h5

# H5 构建
npm run build:h5
```

## 页面结构

```
pages/
├── index/          # 首页 - 任务列表
├── shop/           # 商城 - 积分兑换
├── profile/        # 个人中心
├── task/           # 任务管理
├── community/      # 社区
├── statistics/     # 统计分析
├── settings/       # 设置
├── login/          # 登录
└── register/       # 注册
```
